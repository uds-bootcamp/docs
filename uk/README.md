# Управління програмою UDS Bootcamp

Цей репозиторій містить офіційні керівні документи для UDS Bootcamp. Ці файли визначають стандарти поведінки, академічні вимоги та операційні керівництва для всіх учасників, менторів та персоналу. Дотримання цих політик є обов'язковим і необхідним для підтримки безпечного, продуктивного та справедливого навчального середовища для всіх учасників.

## Опис документів

### [Кодекс поведінки](./CODE_OF_CONDUCT.md)

Цей документ встановлює очікування щодо поведінки в спільноті UDS Bootcamp. Він розроблений для забезпечення безпечного, інклюзивного та професійного навчального середовища, вільного від переслідувань та порушень.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Основні принципи:** Професіоналізм, Повага, Інклюзивність та Співпраця.
  * **Очікувана поведінка:** Активна участь, конструктивний зворотний зв'язок та академічна доброчесність.
  * **Неприйнятна поведінка:** Вичерпний список, що включає переслідування, дискримінацію та деструктивні дії.
  * **Протокол звітування:** Чіткі кроки для повідомлення про порушення та подальший процес забезпечення виконання.

</details>

### [Правила участі](./RULES.md)

У той час як [Кодекс поведінки](./CODE_OF_CONDUCT.md) регулює міжособистісні взаємодії, цей документ визначає конкретні академічні та логістичні зобов'язання, необхідні для успішного завершення програми.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Політика відвідування:** Обов'язкова присутність на живих сесіях, з максимум двома невиправданими відсутностями.
  * **Здача завдань:** Жорсткі терміни, 24-годинний пільговий період (якщо запитано заздалегідь) та вимога добросовісних зусиль для всіх робіт.
  * **Вимоги до участі:** Активна політика увімкненої камери для сприяння спільноті та відповідальності.
  * **Політика трьох страйків:** Процес, за яким учасники можуть бути виключені з програми за порушення, такі як невиправдані відсутності, неподання основних завдань або повторна неучасть.

</details>

<details>

### [Рекомендації щодо випускного проєкту](./CAPSTONE_RECOMMENDATIONS.md)

Цей посібник надає структуру для планування, виконання та представлення успішного фінального випускного проєкту, який слугуватиме портфоліо-гідною роботою.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Основні принципи:** Проєкт повинен демонструвати основні компетенції, вирішувати нетривіальну проблему, бути орієнтованим на дані та мати керований обсяг (MVP).
  * **Ідеї проєктів:** Приклади та концепції для різних спеціалізацій, таких як Data Science та Data Analytics.
  * **Систематична структура:** Покроковий посібник для виконання проєкту, від ідеї та аналізу можливості до контролю версій, документації (`README.md`), розгортання та створення кейс-стаді.

</details>

### [Рекомендації для менторів](./RECOMMENDATIONS_FOR_MENTORS.md)

Це спеціальний посібник для менторів буткемпу, що синтезує ключові принципи з усіх інших документів для надання чіткої структури їхніх обов'язків.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Основні принципи менторства:** Демонстрація професіоналізму, створення безпечного середовища та підтримка академічної доброчесності.
  * **Керівництво з технічної роботи:** Дотримання термінів здачі та забезпечення добросовісних зусиль учасників.
  * **Менторство випускного проєкту:** Допомога підопічним у визначенні керованого обсягу (MVP), посиленні основних принципів та дотриманні систематичної структури виконання.
  * **Комунікація та звітування:** Протокол для ескалації проблем, таких як порушення [Кодексу поведінки](./CODE_OF_CONDUCT.md), учасники, які ризикують отримати страйк, або випадки академічної нечесності до адміністратора програми.

</details>

### [Покращення буткемпу учасниками](./IMPROVEMENT.md)

Цей документ описує, як учасники можуть виявляти проблеми, пропонувати рішення та допомагати впроваджувати покращення в досвід буткемпу.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Керівні принципи:** Співпраця, рішення на основі даних, інклюзивне представництво та прозоре виконання.
  * **Цикл покращення:** Покроковий процес від виявлення можливостей до пілотування та документування результатів.
  * **Робочі групи учасників:** Як когорти можуть організовуватись, визначати обсяг та звітувати про цільові ініціативи.
  * **Канали зворотного зв'язку та відстеження:** Офіційні шляхи для обміну ідеями, реєстрації пропозицій, вимірювання успіху та вирішення конфліктів.

</details>

## Як використовувати ці документи

  * **Для учасників:** Ви повинні прочитати та дотримуватися [`Кодексу поведінки`](./CODE_OF_CONDUCT.md) та [`Правил участі`](./RULES.md). Документ [`Поширені запитання (FAQ)`](./FAQ.md) надає швидку довідку для поширених правил. [`Рекомендації щодо випускного проєкту`](./CAPSTONE_RECOMMENDATIONS.md) будуть вашим основним посібником під час фази фінального проєкту.
  * **Для менторів:** Очікується, що ви будете знайомі з усіма документами для ефективного керівництва вашими підопічними. Вашим основним операційним посібником є [`Рекомендації для менторів`](./RECOMMENDATIONS_FOR_MENTORS.md), який деталізує вашу конкретну роль та обов'язки.

## Запитання та звітування

З будь-яких питань щодо цих документів або для повідомлення про порушення [Кодексу поведінки](./CODE_OF_CONDUCT.md), будь ласка, зв'яжіться з **Адміністратором програми** через призначені приватні канали (наприклад, пряме повідомлення в Discord).
