# Керівні документи UDS Bootcamp

Цей репозиторій містить офіційні керівні документи для UDS Bootcamp. Ці файли визначають стандарти поведінки, вимоги до навчання та операційні процедури для всіх учасників, менторів та організаторів. Дотримання цих правил є обов'язковим і необхідним для забезпечення безпечного, продуктивного та справедливого навчального середовища для всіх учасників.

## Опис документів

### [Кодекс поведінки](./CODE_OF_CONDUCT.md)

Цей документ встановлює норми поведінки у спільноті UDS Bootcamp. Він розроблений для забезпечення безпечного, інклюзивного та професійного навчального середовища, вільного від переслідувань та дискримінації.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Основні принципи:** Професійність, Повага, Інклюзивність та Співпраця.
  * **Очікувана поведінка:** Активна участь, конструктивний зворотний зв'язок та академічна доброчесність.
  * **Неприйнятна поведінка:** Вичерпний список, що включає переслідування, дискримінацію та шкідливу поведінку.
  * **Порядок повідомлення:** Чіткі кроки для повідомлення про порушення та подальший процес реагування.

</details>

### [Правила участі](./RULES.md)

Якщо [Кодекс поведінки](./CODE_OF_CONDUCT.md) регулює міжособистісні взаємодії, цей документ визначає конкретні навчальні та організаційні зобов'язання, необхідні для успішного завершення програми.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Правила відвідування:** Обов'язкова присутність на живих заняттях, допускається максимум дві відсутності без поважної причини.
  * **Здача завдань:** Суворі терміни, 24-годинний пільговий період (за попередньою домовленістю) та вимога сумлінного виконання всіх робіт.
  * **Вимоги до участі:** Правило обов'язково ввімкненої камери для розвитку згуртованості та підвищення відповідальності.
  * **Правило трьох попереджень:** Процес, за яким учасники можуть бути виключені з програми за порушення, такі як відсутності без поважної причини, неподання основних завдань або систематична неучасть.

</details>

### [Поширені запитання (FAQ)](./FAQ.md)

Цей документ надає стислі відповіді на поширені запитання про структуру, правила та вимоги буткемпу, які безпосередньо ґрунтуються на керівних документах.

<details>
<summary><strong>Основні теми</strong></summary>

  * Загальна структура програми та очікування
  * Відвідування, пунктуальність та відсутності

  * Завершення програми та наслідки (включаючи правило трьох попереджень)
  * [Кодекс поведінки](./CODE_OF_CONDUCT.md) та повідомлення про порушення
  * Основи та вимоги до випускного проєкту

</details>

### [Рекомендації щодо випускного проєкту](./CAPSTONE_RECOMMENDATIONS.md)

Цей посібник надає структуру для планування, виконання та представлення успішного фінального випускного проєкту, який можна буде додати до портфоліо.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Основні принципи:** Проєкт повинен демонструвати основні компетенції, вирішувати нетривіальну проблему, базуватися на даних та мати керований обсяг (MVP).
  * **Ідеї проєктів:** Приклади та концепції для різних спеціалізацій, таких як Data Science та Data Analytics.
  * **Систематична структура:** Покроковий посібник для виконання проєкту, від ідеї та аналізу здійсненності до контролю версій, документації (`README.md`), розгортання та створення опису проєкту (кейсу).

</details>

### [Рекомендації для менторів](./RECOMMENDATIONS_FOR_MENTORS.md)

Це спеціальний посібник для менторів буткемпу, який узагальнює ключові принципи з усіх інших документів та чітко структурує їхні обов'язки.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Основні принципи менторства:** Професійність, створення безпечного середовища та підтримка академічної доброчесності.
  * **Супровід виконання завдань:** Контроль дотримання термінів здачі та сумлінного виконання завдань учасниками.
  * **Менторство випускного проєкту:** Допомога підопічним у визначенні керованого обсягу (MVP), закріпленні основних принципів та дотриманні систематичної структури виконання.
  * **Комунікація та звітування:** Порядок ескалації проблем, таких як порушення [Кодексу поведінки](./CODE_OF_CONDUCT.md), учасники, яким загрожує попередження, або випадки академічної нечесності, до адміністратора програми.

</details>

### [Пропозиції учасників щодо покращення](./IMPROVEMENT.md)

Цей документ описує, як учасники можуть виявляти проблеми, пропонувати рішення та допомагати покращувати навчальний процес у буткемпі.

<details>
<summary><strong>Основні теми</strong></summary>

  * **Керівні принципи:** Співпраця, рішення на основі даних, інклюзивність та прозорість впровадження.
  * **Цикл покращення:** Покроковий процес від виявлення можливостей до пілотування та документування результатів.
  * **Робочі групи учасників:** Як когорти можуть організовуватись, визначати обсяг та звітувати про цільові ініціативи.
  * **Канали зворотного зв'язку та відстеження:** Офіційні шляхи для обміну ідеями, реєстрації пропозицій, оцінки успішності та вирішення конфліктів.

</details>

## Як використовувати ці документи

  * **Для учасників:** Ви маєте прочитати та дотримуватися [`Кодексу поведінки`](./CODE_OF_CONDUCT.md) та [`Правил участі`](./RULES.md). Документ [`Поширені запитання (FAQ)`](./FAQ.md) надає швидку довідку для поширених правил. [`Рекомендації щодо випускного проєкту`](./CAPSTONE_RECOMMENDATIONS.md) будуть вашим основним посібником під час фази фінального проєкту.
  * **Для менторів:** Від вас очікується знайомство з усіма документами для ефективного керівництва вашими підопічними. Вашим основним операційним посібником є [`Рекомендації для менторів`](./RECOMMENDATIONS_FOR_MENTORS.md), який деталізує вашу конкретну роль та обов'язки.

## Запитання та повідомлення про порушення

З будь-яких питань щодо цих документів або для повідомлення про порушення [Кодексу поведінки](./CODE_OF_CONDUCT.md), будь ласка, зв'яжіться з **Адміністратором програми** через визначені приватні канали (наприклад, пряме повідомлення в Discord).
